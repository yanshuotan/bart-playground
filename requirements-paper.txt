# Environment for the BART mixing paper.
#
# Captured from the cluster account that produced every stored run under
# diagnosis/store. Both the sampling and the analysis should use it, so that
# the draws and the diagnostics computed from them come from one environment.
#
#     pip install -r requirements-paper.txt
#     pip install -e .
#
# Python 3.10.10.
#
# Two of these pins carry more weight than the rest. numba decides whether a
# re-run reproduces the draws at all: the sampler hot paths are @njit(cache=True),
# and a different numba, llvmlite or CPU can change a float in its last bits,
# which is enough to flip an accept/reject and send a chain elsewhere. arviz
# decides the diagnostics: its R-hat and ESS estimators have been revised
# between releases, so the same draws can yield different numbers under a
# different version.
#
# Seeds are fixed in diagnosis/experiment_fixed100.py and do not vary by host.
